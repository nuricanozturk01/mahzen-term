**Goal:** Cargo workspace with enforced dependency rules, CI on Linux/macOS/Windows, and an empty Iced window — the foundation every later milestone builds on.

## Global Constraints

- Layout and crate names exactly as PLAN.md §3.1: `crates/{core,term,ui-kit,app,platform}`, `xtask/`, `modules/` (empty for now, contains `.gitkeep`).
- Dependency rules (PLAN.md §3.2): `core` → no workspace deps; `platform` → none; `ui-kit` → `core`; `term` → `core`, `platform`; `app` → `core`, `term`, `ui-kit`, `platform`, `modules/*`; `modules/*` → `core`, `ui-kit` only; `core` must not transitively depend on `iced`, `wgpu`, `winit`.
- Edition 2021; `rust-version = "1.99"` set in `[workspace.package]`; `#![forbid(unsafe_code)]` in every crate root.
- Licenses: `MIT OR Apache-2.0`, both license files at repo root.
- Quality gate (CLAUDE.md): `cargo fmt --all --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test --workspace`, `cargo run -p xtask -- check-deps` all pass.
- CI matrix: ubuntu-latest, macos-latest, windows-latest.
- Commits only when the user approves; commit steps below are conditional. The directory is not yet a git repo; `git init` needs the same approval.
- English for code, comments, commit messages.

## Review Focus

- Workspace path containing non-ASCII or spaces (user has Turkish locale paths): `check-deps` must work and report paths correctly.
- A new crate under `modules/` with an unlisted name: must be governed by the `modules/*` glob rule, not silently ignored.
- Dev-dependency and build-dependency edges: a `core` dev-dependency on `app` must still be a violation.
- `check-deps` invoked from a subdirectory or via `cargo xtask`-style alias: must locate the workspace root, not depend on cwd.
- App started without a display (CI/SSH): must exit non-zero with a readable error, never panic with a backtrace.

**Interfaces:**
- Produces in `graph.rs`:
  `pub struct Pkg { pub name: String, pub dir: String /* workspace-relative, '/' separators, e.g. "crates/core"; empty for external */, pub workspace: bool, pub deps: Vec<String> /* all edges: normal+dev+build */ }`
  `pub struct Graph { pub pkgs: Vec<Pkg> }`
  `pub fn load(workspace_root: &Path) -> anyhow::Result<Graph>` (runs `cargo metadata`, uses `workspace_root` argument, not cwd)
